Kéo thả hoặc bấm để tải file export voucher
File cần các cột: Mã Voucher, Ngày sử dụng, Giá trị Voucher, Tên chiến dịch, Trạng thái, Cửa hàng áp dụng, Nhân viên thực hiện, Mã đơn hàng, Hạng thành viên.
Nếu file có thêm cột Số điện thoại hoặc Mã khách hàng, dashboard sẽ tự bật thêm cảnh báo trùng số điện thoại và tài khoản ảo.
Cách dùng hằng ngày: mỗi sáng tải file export mới nhất vào đây. Dashboard tự tính lại toàn bộ chỉ số, ngân sách và cảnh báo. Cấu hình ngân sách và ngưỡng cảnh báo được lưu trên trình duyệt của bạn, không cần nhập lại.
Để gửi link cho người khác xem luôn, không cần tải file: sau khi có số liệu, bấm "Lưu dữ liệu (data.json)" ở góc trên, rồi đưa file data.json đó lên cùng thư mục với trang này (ví dụ commit lên GitHub cạnh index.html). Trang sẽ tự nạp lại mỗi khi có ai mở link.
